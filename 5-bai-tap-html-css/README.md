# Bài tập Thiết kế Web — HTML & CSS

Bài tập được đánh số theo các mục trong tài liệu học. Mỗi bài có một file ZIP riêng, giữ nguyên mã nguồn HTML/CSS/JavaScript đã xóa comment.

| Số bài trong sách | Nội dung | Tải bài |
| --- | --- | --- |

| **2.1.6** | Định dạng hỗn hợp | [2.1.6.zip](2.1.6.zip) |
| **2.1.7** | Thuộc tính float và clear | [2.1.7.zip](2.1.7.zip) |
| **2.2.1** | CSS box model — yêu cầu thực hiện: danh sách sản phẩm | [2.2.1.zip](2.2.1.zip) |
| **2.3.1** | Menu ngang một cấp | [2.3.1.zip](2.3.1.zip) |

## Cách chạy

1. Tải file ZIP của bài cần xem.
2. Giải nén file.
3. Mở file `.html` trong thư mục vừa giải nén bằng trình duyệt Chrome, Edge hoặc Firefox.

Không cần cài đặt thư viện hay chạy server. Bài 2.2.1 có ảnh minh họa SVG thay cho ảnh gốc trong sách.
