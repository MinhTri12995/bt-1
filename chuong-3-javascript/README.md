# Chương 3 — JavaScript

Các bài tập JavaScript theo sách **Bài tập Thiết kế Web**, phần chương 3 trong ảnh chụp. Mỗi bài được đóng thành một file ZIP riêng; mã nguồn HTML, CSS và JavaScript không có comment.

| Bài | Tên bài | Tải ZIP |
|---|---|---|
| **3.1.1** | Tính lãi suất ngân hàng (lãi đơn) | [3.1.1.zip](3.1.1.zip) |
| **3.1.2** | Kiểm tra năm nhuận | [3.1.2.zip](3.1.2.zip) |
| **3.1.3** | Đổi năm dương lịch sang năm âm lịch (Can–Chi) | [3.1.3.zip](3.1.3.zip) |
| **3.2.1** | Hiệu chỉnh theo sự kiện chuột / DOM | [3.2.1.zip](3.2.1.zip) |
| **3.2.2** | Tra cứu giá hoa quả | [3.2.2.zip](3.2.2.zip) |
| **3.2.3** | Tính số ngày trong tháng | [3.2.3.zip](3.2.3.zip) |

## Cách chạy

1. Tải ZIP của bài muốn xem.
2. Giải nén.
3. Mở file `index.html` trong thư mục bài bằng trình duyệt.

Không cần cài đặt môi trường hoặc kết nối mạng. Các file `style.css`, `script.js` và hình minh họa được đóng gói kèm bài tương ứng.

**Lưu ý:** Đề bài 3.2.3 trong ảnh mới chụp thấy một phần, nên phần nhập tháng/năm và xác định số ngày được triển khai theo nội dung tiêu đề và yêu cầu đọc được. Bài 3.2.1 dùng hình SVG minh họa thay ảnh sách.
